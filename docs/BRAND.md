# SellOS brand tokens (SOS-P1-06A)

Approved by Jayman. They replace the placeholder tokens from P0.10 (brand #1d4e5f, accent #c98a2b, Inter).
The single source is `frontend/src/theme/tokens.js`. Each company may override the brand colour at runtime.

| Token | Value |
| --- | --- |
| `--sos-brand` | #0f4c35 |
| `--sos-brand-dark` | #0a3626 |
| `--sos-brand-mid` | #2a7a5a |
| `--sos-brand-light` | #e3f0ea |
| `--sos-accent` | #e8954a |
| Headings | Syne |
| Body | DM Sans |

The page shows the company name from SellOS Settings, and "SellOS" when none is set, never the site name.
The tab icon is the company logo when SellOS Settings has one, otherwise the SellOS default icon.
